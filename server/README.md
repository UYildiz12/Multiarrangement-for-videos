# Server (FastAPI)

This folder will host the backend API that powers the web UI while keeping the existing MA library intact.

Responsibilities:
- set-cover batch generation (including flex)
- adaptive LTW selection
- RDM fusion + evidence matrices + inverse-MDS
- session + trial storage via Supabase Postgres
- media metadata + signed URLs via Supabase Storage

Planned hosting: Render (free tier initially).

Status: scaffold only (no dependencies installed yet).
